# Naming decision research — 2026-10-01

Status: ranked research recommendation, not adoption. Keep KAIROS and PR #737.
No domain, account or package has been registered or purchased.

## What the name must communicate

KAIROS is an agent-facing persistent protocol system: it bridges pretrained
knowledge of generic practice and this user's or team's actual way of working.
A model can know Git perfectly and still create a PR using the wrong local
procedure. The name must make sense as the system consulted before that action.
The [brief](BRIEF.md) defines this north-star test and the full constraints.

Gaming and team sports offer a useful metaphor: capable players still need the
team's rules and agreed plays. Multiplayer alone describes multiple actors;
cooperation alone describes an attitude. The product additionally preserves,
discovers and guides execution of local procedure. A name must work for one
person and their agent as well as a large team.

## The ten-name decision set

Ranking is editorial judgment about product fit, clarity, distinctiveness and
observed collisions, not a numerical measurement. These are three finalists
and seven rejected directions; the attached probe files retain the broader
screening trail, not additional finalists.

| Rank | Name | Decision and reason |
| --- | --- | --- |
| 1 | **SquadRules** | Leading team/co-op direction. Skilled agents follow this squad's rules before acting. Familiar words, clear spelling, portable beyond MCP. |
| 2 | **DefinedWay** | Strongest literal philosophy: use the locally defined way instead of inventing a plausible one. Works naturally for individuals, but less evocative of cooperation. |
| 3 | **CoopCue** | Shortest co-op direction: shared cues guide coordinated action. Memorable, but “cue/queue” and “coop/co-op” create spoken ambiguity; cues can sound optional. |
| 4 | SamePlaybook | Excellent shared-procedure meaning, weak distinctiveness. An adjacent agent-context product already uses “same playbook” positioning. |
| 5 | MEMORY.md / memory-md / memory_md | Attractive persistent-context and Markdown association, but direct agent-memory and MCP collisions, unavailable exact .md domain, and a memory-only interpretation. Treat punctuation/case as one brand family. |
| 6 | SquadPact | Strong team agreement metaphor, but an existing sports-team coordination product uses the exact name. |
| 7 | CoPlay | Very strong cooperation meaning, but an existing AI/Unity product offers MCP tooling under this name. |
| 8 | TeamWay | Clear local team method, but existing software uses the exact name. |
| 9 | SharedPlay | Good multiplayer association, but established gaming-brand history and unavailable exact .com. |
| 10 | WorkDefault | Captures local defaults, but the exact term is an established adware name. An available domain cannot repair that association. |

## Finalists and domain evidence

Exact `gcloud domains registrations get-register-parameters` checks on
2026-10-01 returned the following. “Available” means offered for registration at
lookup time, not free of charge or secured. Prices are API yearly quotes in USD,
not a guarantee of checkout totals or future renewals.

| Name / canonical slug | .com | .dev | .io |
| --- | --- | --- | --- |
| SquadRules / `squadrules` | AVAILABLE, $12 | AVAILABLE, $12 | AVAILABLE, $60 |
| DefinedWay / `definedway` | AVAILABLE, $12 | AVAILABLE, $12 | AVAILABLE, $60 |
| CoopCue / `coopcue` | AVAILABLE, $12 | AVAILABLE, $12 | AVAILABLE, $60 |

**SquadRules:** “Check SquadRules before creating the PR” naturally means consult
this team's operating rules. Its weakness is ordinary game-server “squad rules”
language, visible in [Command Squad's rules](https://commandsquad.net/rules).
It can sound like a moderation rulebook and understate persistence/execution.
Use the descriptor **persistent local protocols for agents** to clarify scope.

**DefinedWay:** “Check DefinedWay before creating the PR” points directly at a
previously agreed procedure. It avoids making the product team-only. The phrase
is ordinary English and emotionally restrained; the name alone does not convey
persistence or cooperation. It is the strongest alternative if semantic precision
matters more than the gaming/team association.

**CoopCue:** “Check CoopCue before creating the PR” evokes coordination, but needs
more explanation than the other two. Pronounce it “co-op cue.” Its compactness
comes with spelling and pronunciation costs; it ranks third for that reason.

## Why the seven alternatives lost

- **SamePlaybook:** [Opmore](https://www.opmore.ai/) already positions its agent
  context product around the same playbook inside existing tools. This is a
  distinctiveness judgment, not a claim of trademark ownership. Its exact domains
  being available does not resolve the nearby positioning.
- **MEMORY.md family:** [adi0x/memory-md](https://github.com/adi0x/memory-md)
  describes an agent experiential-memory standard;
  [pavex/mcp-memory-md](https://github.com/pavex/mcp-memory-md) is a memory MCP
  server. Changing separators or case does not remove this direct category overlap.
  See the focused domain and spelling findings below.
- **SquadPact:** [SquadPact](https://www.squadpact.com/) already provides sports-team
  scheduling and attendance. The metaphor leads straight into an occupied brand;
  the exact .com was UNAVAILABLE.
- **CoPlay:** [Coplay products](https://coplay.dev/products) include AI assistance
  for Unity and MCP offerings. This is a direct adjacent-software collision;
  the exact .com was UNAVAILABLE.
- **TeamWay:** [Teamway ERP documentation](https://system.teamway.om/) establishes
  exact-name software use. The exact .com was UNAVAILABLE.
- **SharedPlay:** historical gaming use is documented by
  [LeoVegas's 2021 report](https://attachment.news.eu.nasdaq.com/a8dd034b9fd8463a80c9130ee76508272).
  This is historical collision evidence, not a claim about current company ownership.
  The exact .com was UNAVAILABLE.
- **WorkDefault:** [PCrisk's WorkDefault analysis](https://www.pcrisk.com/removal-guides/15983-workdefault-adware-mac)
  records the exact adware name. Reject despite an AVAILABLE exact .com.

## MEMORY.md and the suggested variants

The user's supplied search output reported `memory.md` UNSUPPORTED. An exact
Cloud Domains lookup confirmed UNSUPPORTED: that provider cannot establish
registration availability for this suffix. On 2026-10-01 the visible result at
[Register.domains](https://register.domains/search-domain?domain=memory.md)
reported **memory.md — Not Available**. Its suggestions are different domains,
not evidence that memory.md can be purchased.

The supplied search output also suggested `memory.io` as available. A subsequent
exact registration-parameters lookup returned **UNAVAILABLE**. Treat the exact
lookup as the current observation; do not rely on a cached suggestion list.

The exact hyphenated domains `memory-md.com`, `memory-md.dev` and
`memory-md.io` returned AVAILABLE at $12, $12 and $60 USD per year respectively.
That makes the spelling technically possible, but does not resolve the existing
agent-memory brand collision.

`MEMORY-md` and `memory-md` express the same spoken identity. Case changes do
not distinguish a domain name. `memory_md` is a possible spelling in some code
contexts, but is unsuitable as the ordinary registrable hostname label for a
consistent cross-platform brand. Neither separator supplies semantic distinction
from existing memory-md projects. An absent technical record for a particular
variant would not clear this brand-family collision.

The appealing idea is continuity: the agent retains how the team works. Preserve
that idea in product positioning. Memory alone understates discovering the right
procedure and following its execution contract, which distinguish KAIROS from a
Markdown memory file or storage tool.
